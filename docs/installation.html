📋 Prerequisites

Before installing TestFlow Pro, ensure you have the following software installed on your system:

Required Software

Software Minimum Version Purpose
Node.js v18.0.0+ JavaScript runtime
npm v8.0.0+ Package manager
Git Latest Version control

Optional (for specific features)

Software Purpose
MySQL Database testing with MySQL
ODBC Driver ODBC database connections
DB2 Client DB2 database testing 
# Verify Node.js installation
node --version

# Verify npm installation
npm --version

# Verify Git installation
git --version

🚀 Installation Steps

1

Clone the Repository

Clone TestFlow Pro from your repository:

git clone https://github.com/afsarali273/TestFlowPro.git
cd TestFlowPro
2

Install Backend Dependencies

Install all required Node.js packages:

npm install

This will install:

  • TypeScript and ts-node
  • Playwright for UI testing
  • Axios for HTTP requests
  • Faker.js for data generation
  • Database drivers (MySQL, ODBC)
  • And more...
3

Install Frontend Dependencies

Navigate to the frontend directory and install dependencies:

cd frontend/TestEditor
npm install --legacy-peer-deps
cd ../..

Note: The --legacy-peer-deps flag is required due to peer dependency conflicts in some packages.

4

Install Playwright Browsers

Install browser binaries for UI testing:

npx playwright install

This installs Chromium, Firefox, and WebKit browsers.

5

Verify Installation

Run a sample test to verify everything is set up correctly:

# From project root
npm test

🔧 Configuration

Environment Files

Create environment-specific configuration files in the project root:

# Create base configuration
touch .env

# Create environment-specific configs
touch .env.dev
touch .env.qa
touch .env.prod

Sample .env Configuration

# Base URL for API tests
BASE_URL=https://api.example.com

# Parallel execution threads
PARALLEL_THREADS=4

# Test timeout (milliseconds)
TEST_TIMEOUT=30000

# Browser settings for UI tests
HEADLESS=true
BROWSER=chromium
SLOW_MO=0

# Database configuration (optional)
DB_USERDB_TYPE=mysql
DB_USERDB_HOST=localhost
DB_USERDB_PORT=3306
DB_USERDB_USER=root
DB_USERDB_PASSWORD=secret
DB_USERDB_NAME=testflow

Environment-Specific Overrides

Create environment-specific files that override base configuration:

.env.qa

BASE_URL=https://qa-api.example.com
HEADLESS=false
PARALLEL_THREADS=2

.env.prod

BASE_URL=https://api.example.com
HEADLESS=true
PARALLEL_THREADS=8

💡 Tip: Use ENV=qa npm test to load environment-specific configuration.

🐛 Troubleshooting

Issue: Node Version Mismatch

Symptom: Errors during npm install or test execution

Solution:

# Check Node version
node --version

# Use nvm to switch versions
nvm install 18
nvm use 18

Issue: Playwright Browser Installation

Symptom: UI tests fail with "Browser not found" error

Solution:

# Install Playwright browsers
npx playwright install

# Install system dependencies (Linux)
npx playwright install-deps

Issue: Database Connection Issues

Symptom: Database queries fail or timeout

Solution:

  • Verify database credentials in .env file
  • Ensure database server is running
  • Check firewall settings
  • Test connection with database client

Issue: Frontend Build Errors

Symptom: npm install fails in frontend directory

Solution:

# Clear cache and reinstall
cd frontend/TestEditor
rm -rf node_modules package-lock.json
npm install --legacy-peer-deps

Issue: Permission Issues (macOS/Linux)

Symptom: Permission denied errors

Solution:

# Fix permissions
chmod +x src/runner.ts

# Or use sudo for npm install (not recommended)
sudo npm install

Issue: Port 3000 Already in Use

Symptom: Frontend fails to start

Solution:

# Kill process using port 3000
lsof -ti:3000 | xargs kill -9

# Or change port in package.json
"dev": "next dev -p 3001"
