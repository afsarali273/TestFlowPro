🎯 Overview

The AI Chat Assistant is an intelligent test generation tool that helps you create comprehensive test suites using natural language, cURL commands, Swagger specifications, and UI descriptions.

AI Chat Assistant Interface

✨ Key Benefits

  • Generate tests 10x faster than manual authoring
  • No programming knowledge required
  • Comprehensive test coverage automatically
  • Support for both cloud and local AI
  • Convert existing cURL/Swagger to tests instantly

⚙️ Setup & Configuration

Accessing the AI Assistant

The AI assistant is available via a floating chat icon at the bottom-right corner of the dashboard.

1

Open Dashboard

cd frontend/TestEditor
npm run dev

Access at: http://localhost:3000

2

Click AI Chat Icon

Look for the animated purple-blue gradient icon with sparkle effects at the bottom-right corner

3

Choose AI Provider

Select between GitHub Copilot (cloud) or Ollama (local)

Option 1: GitHub Copilot (Recommended)

OAuth Authentication

1

Click "OAuth Login"

Device code will be displayed (e.g., ABCD-1234)

2

Authorize on GitHub

Browser opens automatically, enter the code and authorize

3

Start Generating

Green status indicator shows when authenticated

Manual Token Method

# 1. Generate Personal Access Token on GitHub
# Go to: Settings → Developer settings → Personal access tokens
# Scopes needed: copilot, user:email

# 2. Click "Manual Token" in AI Assistant
# 3. Paste token and save

Option 2: Ollama (Local AI)

Installation

# Install Ollama
curl -fsSL https://ollama.com/install.sh | sh

# Pull a model
ollama pull codellama

# Start Ollama server
ollama serve

Benefits: Complete privacy, no API costs, offline capability

🔗 cURL Import & Conversion

Paste cURL commands, test them live, and convert to test suites instantly.

Step-by-Step Process

1

Paste cURL Command

curl -X POST https://api.example.com/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"user@example.com","password":"secret"}'
2

Test cURL (Optional)

Click "Test cURL" to execute and see actual response

  • View status code
  • See response time
  • Inspect response body
  • Check headers
3

Apply JSONPath Filter (Optional)

$.token
$.data[0].id
$..email
4

Generate Test Suite

AI converts cURL to complete test with assertions and variable storage

Features

✅ Smart Parsing

Extracts method, headers, body, and URL automatically

✅ Live Testing

Execute cURL before conversion to verify it works

✅ Auto Assertions

Generates appropriate assertions based on response

✅ Variable Storage

Identifies and stores important response values

📋 Swagger/OpenAPI Import

Import API specifications and generate comprehensive test coverage automatically.

Import Methods

📄 Upload File

Upload .json, .yaml, or .yml files

🔗 From URL

Provide Swagger spec URL

📋 Paste Content

Paste JSON or YAML directly

Example Swagger Spec

openapi: 3.0.0
info:
  title: User API
  version: 1.0.0
paths:
  /users:
    get:
      summary: Get all users
      responses:
        '200':
          description: Success
          content:
            application/json:
              schema:
                type: array
                items:
                  $ref: '#/components/schemas/User'
    post:
      summary: Create user
      requestBody:
        required: true
        content:
          application/json:
            schema:
              $ref: '#/components/schemas/User'
      responses:
        '201':
          description: Created

Generated Test Coverage

  • ✅ Test cases for each endpoint
  • ✅ Positive test scenarios (200, 201, 204)
  • ✅ Negative test scenarios (400, 401, 404, 500)
  • ✅ Request/response schema validation
  • ✅ Parameter validation tests
  • ✅ Authentication tests
  • ✅ Edge cases and boundary tests

💡 Best Practices

Be Specific

Include endpoint URLs, HTTP methods, expected status codes, and validation rules

Provide Examples

Give sample request/response data for better test generation

Iterate & Refine

Review generated tests and ask AI to modify specific parts

Combine Tools

Use cURL for quick tests, Swagger for comprehensive coverage

🎯 Pro Tips

  • Start with simple prompts and add details iteratively
  • Use "Test Cases Only" mode to add to existing suites
  • Test cURL commands before converting to verify they work
  • Use Playwright codegen for complex UI interactions
  • Save generated tests and refine them manually if needed
